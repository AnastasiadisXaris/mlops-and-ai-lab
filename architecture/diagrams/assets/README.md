# Diagram Assets

## Purpose

This folder stores supporting assets for architecture diagrams.

Examples:

- exported images
- draft diagrams
- presentation visuals
- SVG assets
- infrastructure screenshots
- cloud topology exports

---

# Recommended Structure

```text
assets/
│
├── exported/
├── drafts/
├── presentations/
├── references/
└── screenshots/
```

---

# Folder Descriptions

| Folder | Purpose |
|---|---|
| exported | final PNG/SVG exports |
| drafts | unfinished diagrams |
| presentations | slides and presentation visuals |
| references | inspiration/reference diagrams |
| screenshots | cloud dashboards and infrastructure screenshots |

---

# Export Recommendations

Preferred formats:

| Format | Use |
|---|---|
| SVG | scalable high-quality diagrams |
| PNG | presentations and documentation |
| PDF | printable architecture documentation |

---

# Naming Conventions

Use descriptive names:

```text
rag-architecture-v1.svg
mlops-pipeline-final.png
kubernetes-topology.pdf
```

Avoid:

```text
final-final-real-v2.png
```

The ancient curse of engineering file naming.

---

# Versioning Strategy

Update assets when:

- architecture changes
- infrastructure evolves
- services are added
- scaling strategy changes
- deployment topology changes

---

# Best Practices

- keep source diagrams editable
- export optimized versions
- organize by project/domain
- maintain consistent naming
- version important architecture milestones

---

# Long-Term Vision

This folder evolves into:

```text
Visual Engineering Archive
    ↓
Architecture Knowledge Base
    ↓
Operational System Atlas
```

Good diagrams reduce complexity.

Great diagrams reduce confusion before it becomes production downtime.
