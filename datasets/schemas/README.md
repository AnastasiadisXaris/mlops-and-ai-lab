# Dataset Schemas

## Purpose

This folder stores schema definitions for datasets.

Schemas define:

- columns
- types
- constraints
- validation rules

---

# Example Schema

```json
{
  "customer_id": "string",
  "age": "integer",
  "purchase_amount": "float"
}
```

---

# Benefits

- validation
- consistency
- reproducibility
- automated checks

---

# Recommended Formats

- JSON Schema
- YAML
- Pandera schemas
