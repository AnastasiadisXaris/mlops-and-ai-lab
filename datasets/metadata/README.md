# Dataset Metadata

## Purpose

This folder stores metadata describing datasets.

Metadata may include:

- source
- version
- owner
- schema
- preprocessing history
- update frequency

---

# Example Metadata

```json
{
  "dataset": "consumer_preferences",
  "version": "1.0",
  "rows": 12000,
  "features": 28
}
```

---

# Why Metadata Matters

Metadata improves:

- discoverability
- governance
- reproducibility
- collaboration
